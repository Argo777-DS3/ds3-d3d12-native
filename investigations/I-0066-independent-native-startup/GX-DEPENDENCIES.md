# Native D3D12 path: dependencies on state the original GX set-up would have produced

Wave-1 closure input ([WAVE1-CLOSURE](WAVE1-CLOSURE.md) §3), 2026-10-19: a static inventory delegated to Sonnet 5.5 (D-0159 rules) and
spot-checked by Opus against the code (4961ABD in light_producers.cpp FogRecord, [144961BF8] in PublishNativeSceneContext, root+0x5368
in NativeSceneRootFrame): non-canonical until each line is used; INFERRED marks stay as written.

Read-only static inventory of the worktree `hungry-leakey-6c71bf` (branch tip 6ffcbf9d). Facts come from code and code comments;
anything inferred is marked INFERRED. Paths are relative to `native/`; `GB` = `frame/game_bootstrap/`.
Part names: 01_state, 02_frame_lifecycle, 03_engine_cpu_owners, 05_selected_scene, 07_scene_lighting, 09_model_admission,
10_options_and_passes, 11_yebis_host, 12_scene_collect, 14_scene_step_and_storage, 15_cpu_service_and_input, 16_offscreen_and_movies,
17_render_step, 18_resource_admission, 20_startup_phases, 21_effects, 22_setup (all `.inc`).

Risk classes: ZONE-WIDE = a wrong value could break or visibly change a whole zone or every zone; FEATURE = one feature/family;
LOCAL = one object or diagnostics only.

Method note: in the native path the GX device, the display object `[144961AB0]` and the old GX set-up (`D56E90`, `D573B0`, `B5E00`,
`48B80`, `D59E90`'s GX part) never run. The module (a) builds the engine's CPU-side classes genuinely (constructors run, GPU
initialisers skipped), (b) replaces whole engine functions by hooks, (c) re-produces on the native side what the engine's GX
banks/objects would hold. Everything below is a case of (a)-(c) where the engine CPU code still reads or assumes the result.
