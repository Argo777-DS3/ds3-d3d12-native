**Conventions.**
- « Native seen »: a run in the records whose pictures or rows showed the page natively. « as the original's » = MENUS-NATIVE-GAPS §4's wording
  (same page, text, icons, layout on side-by-side shots). Run names are those of the records (`NativeNNNN` / `ReferenceNNNN` are the wave-1 numbered runs).
- Pilot units = screen pixels of Pilot-Game (1280x720 window, client at 8,31; scaled onto larger windows). `P` = Pilot-Game action. Keys: Esc vk 27, E vk 69
  (confirms; Enter does nothing), Z vk 90 forward, arrows move the cursor. Clicks only select a row, E confirms; pages that ignore Esc take a right click
  (opens `02_045_PC_CommandList`) then its Back entry (790, 508).
- Saves: **ALPHA-COPY** = Run-AlphaCast's default copy `shebang-zones-epsilon-m45-20261013-045053` (SHA-256 8FA5E590...9A1D9C), Alpha at Firelink, Fire Orb;
  `-SaveCopy/-SaveCopySha256` for another. Alpha is Thomas's real game: a copy only. **ETA** = the m40 zone save (`-Continue`; holds every bonfire; SHA-256
  1E905EF8842655C605E175F574BCA5D2B46D1011E8E473142E1577A09FE24EB4), a test character. **DELTA** = Dreg Heap zone save (portrait/Quit runs).
  A Shebang save holds ten profiles: New Game opens the « Cannot create any more profiles » box (see M12).
- `Run-AlphaCast.ps1` order: title notices, optional `-TitleSteps`, Load Game (first row = Alpha) or `-Continue`, 45 s in game, then `-MenuTour`/`-OptionsTour`/
  `-BonfirePages`/`-QuitPortrait`/... `Run-PilotPair.ps1 -Tag t [-Pilot CharMake|LoadGame] [-ColorSelect] [-FaceDetail] [-DeleteProfile] -TestSave -TestSaveSha256`
  runs Reference then Native. Every run is announced, offline, hash-restored (WORKFLOW « Live game rule »).
- Esc-menu icon positions (y 390): the runner's `-MenuTour` uses x 263 Equipment, 323 Inventory, 388 Status, 453 Messages(?), 518 System; LIVE-RUN-NOTES gives 263, 329, 394, 460, 525 (the runner uses the notes' since I-0140 tranche 30).
  The two sets differ by a few units (window placement): check on a shot. The Game Options tab row is at y 192, 60 apart from x 323 (eight tabs: Game 323, Camera 383,
  Sound and display 443, Brightness 503, Network 563, Input device 623, Graphics 683, Quit Game 743).
- The names of the in-game menu items follow the game's English; the page-to-label join (e.g. « Messages » = which movie) is INFERRED where marked.
- `Map` column: menus belong to no map; « any » = any zone, « m40 » = Firelink Shrine (the Alpha/Eta spot), « title » = before a save loads.
