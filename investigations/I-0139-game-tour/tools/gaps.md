## Gaps

1. **Several flags per scene, one id per run.** `witness-flag.txt` takes one `id value`. Smallest tool: `test-flags.txt` (many `id value` lines, applied once the world is ready, again on F5) plus `-SetFlags` in the pilots; a boss-flag subset is already in `test-revive.txt`.
2. **Scenes with no EMEVD caller (24 bundles, C39 to C43).** Their triggers are in Lua, AI or ESD scripts or in game code, which this sheet did not read. Smallest tool: `witness-cutscene.txt` holding an id that calls the engine's request function (`FUN_140CE2810`, REMO-CUTSCENES-NATIVE §2; its signature would be read first).
3. **Trigger conditions only partly decoded.** The flags are listed as the events show them (the `1003[2]`, `1003[101]`, `3[0]` packings are INFERRED). Events that are templates with parameters (13300412, 13705644, 15105713, and the `common_func` templates behind most object events) show entity 0 in the dump. Smallest tool: a resolver that expands each `2000[0]` / `2000[6]` call into its template with the arguments (the dumps hold both the calls and the template bodies).
4. **`m51_01` positions.** The MSB of `m51_01` is not in the recovered set (`map/mapstudio/m51_01_00_00.msb.dcx` did not match a hash in `Data1` or `DLC2`): the Gael scenes' regions (5112800 and others) and area 307's warp point have no coordinates. Smallest tool: find that MSB's real name in the DLC2 index with a hash scan like `Find-RemoEmevd.ps1`.
5. **English prompt and subtitle text.** The prompt text ids (3001810, 9322, 9330, 9344 ...) are numbers: the base game's `menu.msgbnd` (ActionButtonText) was not recovered (`msg/engus/menu.msgbnd.dcx` and a few variants matched no hash); only the DLC bundles are on disk. The cutscenes' subtitles (TalkParam) were not read.
6. **What an object is.** Levers, lifts, doors, bridges and bells are one family of object animations; telling them apart needs the model names (`oNNNNNN`): smallest tool = list each model's asset name from its bundle. Dragons and giants likewise need the character names (`cNNNN`). The Lords of Cinder thrones and the Firelink tower have no named instruction: the ceremony conditions are there, the visible change is OPEN.
7. **The remo bundles' content** (who appears, what each cut shows) is read only for the census's 72 files; the five `DLC2` bundles, `s35_00_0051` and `s45_00_0090` were not opened. Smallest tool: extend I-0069's remobnd census to them.
8. **Boss names** of the 26 registry flags are INFERRED; this sheet's evidence suggests the Archdragon Peak pair (13200800 / 13200850) may be swapped in `boss-flags.json` (C07, C08, C09). Killing each in turn would settle it.
9. **Bink.** The opening and the end roll are reached only through the New Game route and flag 20 (`menus.md`, `endings-dlc.md`); no other movie file exists.
