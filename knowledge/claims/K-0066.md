# K-0066 — WorldChrMan task boundary and shared character module phase

Status: `CONFIRMED`

## Claim

Exact RTTI and constructor stores identify `WorldChrManImp`'s embedded
scheduler records as two SPRJ task families:

- `SprjEzUpdateTask<SprjEzRabbitTask, WorldChrManImp>`, deriving through
  `SprjEzRabbitTaskBase -> SprjEzTask -> FD4TaskBase -> FD4ComponentBase`;
- `SprjEzVoidTask<SprjEzTask, WorldChrManImp>`, deriving through
  `SprjEzTask -> FD4TaskBase -> FD4ComponentBase`.

The manager callback family reaches 11 exact `ChrIns` virtual adapters. Vtable
comparison proves which stages are common versus specialized for PlayerIns and
EnemyIns. Shared slot 23 is a five-instruction thunk to ChrCtrl body
`0x005C7DB0`; it passes the live update delta and synchronizes the
constructor-proved ActionFlag, TimeAct, BehaviorData and physics modules before
dispatching shared ChrCtrl slot 31 (`0x005C9DC0`). Its TimeAct edge calls
`0x009B48D0`, which copies the ring's current insertion index `+0xC0` to prior
index `+0xC4`.

This is a shared scheduled module boundary, not a shared correction. LTF and
TRTF retain distinct PlayerCtrl methods/state, and the I-0008 TimeAct writer
retains its own producer and ring contract.
