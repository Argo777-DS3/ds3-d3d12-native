# K-0068 — Engine-wide SPRJ timeline construction

Status: `CONFIRMED`

## Claim

Exact-build RTTI and constructors establish an engine-wide task graph rooted in
`NS_SPRJ::SprjTaskImp`. Startup constructs
`SprjTimeLineTaskGroupSeed -> SprjTaskGroupSeed`, populates exactly 97 named
group seeds from a static table covering numeric IDs `0x00..0x60`, folds 88
six-lane relation vectors into them, and materializes 97
`SprjTimeLineTaskGroupIns -> SprjTaskGroupIns` objects.

`SprjTaskGroupImp` does not independently construct anonymous buckets. For
each ID it extracts the already materialized object from the temporary seed,
clears the seed slot and activates the object. It therefore owns a transferred
array of named timeline-group instances. `SprjEzTaskProxy` phase IDs select
these instances directly.

The recovered names span the complete frame lifecycle and multiple peer
subsystems: core managers, character/behavior/physics, game flow, networking,
location/world, cloth, UI, sound, camera, LOD, graphics, draw/flip and frame
end. `SprjTimeLineTaskGroupIns` registers its static name and retained
relations into a lower-level external execution graph and removes them through
a separate virtual method.

## Proof basis

- Exact RTTI and hierarchy records in
  `evidence/I-0015/static/character-runtime-spine/key-module-rtti.json`.
- Read-only constructor and virtual-method exports under
  `evidence/I-0015/static/engine-task-graph/`.
- Deterministic exact-hash extraction of all 97 descriptors and 88 relation
  vectors in `task-timeline-descriptors.json`.
- Canonical structural account in `TASK-GRAPH.md` and cross-linked function,
  type/field and relation catalogs.

## Limits

- The four numeric descriptor fields and six relation-lane meanings do not yet
  have original enum/field names.
- Value `0x62` is confirmed as a skipped empty relation entry. The remaining
  values are confirmed group references; their lane and ordering semantics are
  not assigned.
- Numeric group order and relation-record order do not alone prove serial
  execution. Within-group ordering and worker affinity remain unknown.
- The lower-level graph's exact class identity is unknown because the examined
  vtables do not expose valid MSVC RTTI through the standard parser.
- This is a static architecture claim. It changes no LTF/TRTF logic and adds no
  runtime or gameplay-correctness claim.
