# K-0081 — Timeline relation consumer

Status: `CONFIRMED`

## Claim

The six exact static SPRJ relation lanes are compiled to bit masks, retained
by exact runtime timeline group objects, and forwarded to a lower-level
six-cell-per-group matrix. That matrix stores group tokens and control values;
the graph's state/dispatch path reads those cells and takes distinct branches
for values 0 through 5. The static relations are therefore consumed by a
real graph state machine, not merely enumerated or displayed.

## Proof basis

- [Bounded producer/consumer reconstruction](../../evidence/I-0015/static/engine-task-graph/RELATION-CONSUMER-BOUNDARY.md).
- Read-only/no-analysis exact-build Ghidra C and assembly exports under
  `evidence/I-0015/static/engine-task-graph/relation-consumer/`.
- Deterministic architecture catalog validation.

## Limits

The lower-level graph's original type name, lane names, dependency direction,
real execution order, worker affinity and temporal semantics remain unknown.
The distinct numeric control branches do not license semantic enum names.
No live game acquisition or LTF/TRTF change occurred.
