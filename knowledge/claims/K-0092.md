# K-0092 — Shared event-state and Lua-root coordinator

Status: `CONFIRMED`

## Claim

Exact `0x00DE5A40` reads the separately `FieldArea`-published Lua root
and `SprjEventManImp` global, queries the manager's exact
`SprjEventDeadResetState` child at `+0x10`, invokes root/proxy methods,
and in one guarded branch writes state integer `2` to that child at
`+0x08`. It also reads `FrpgNetManImp` fields. Thus event state and Lua
services meet in a bounded common consumer without becoming one object.

## Proof basis

[Event/Lua coordinator boundary](../../evidence/I-0015/static/event-boundary/EVENT-LUA-COORDINATOR-BOUNDARY.md),
exact globals and constructor-installed RTTI, getter body, selected
headless decompilation/assembly and direct-operand census.

## Limits

The input object's type, coordinator scheduling, script callback routing,
state-2 meaning, network protocol and live consequences remain UNKNOWN.
The raw direct-operand census is not an alias-complete reference count.
I-0016 cycle 3 [classified all three direct coordinator DATA references](../../evidence/I-0016/static/event-coordinator-boundary/EVENT-COORDINATOR-CALLER-BOUNDARY.md)
as exception/unwind metadata and found no direct executable-section rel32
CALL/JMP candidate. This closes that bounded caller/registration test without
changing the claim or excluding indirect dispatch.
