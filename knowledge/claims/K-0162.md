# K-0162 — correction de portée du polling `GetData`

Status: `CONFIRMED` before and after this wording correction. No status promotion or new runtime observation.

The earlier ledger wording said `0x1400DC410` retried its first two `GetData` calls. [Exact-build ASM](../../decompiled/DS3-1152-F-000DC410.asm.txt) separates two **sites** of the same status-only loop: `0x1400DC457` makes the initial call with null output and size zero; if its result is nonzero, `0x1400DC483` repeats that status-only call through the loop at `0x1400DC464–48A`. At `0x1400DC4A8` a different call requests 16 output bytes once; the function does not test that return before continuing. The wording is narrowed in K-0162 and in the two I-0026 query/frame notes. This correction does not establish the query's GPU-command coverage or an arena-retirement fence.
